Entry classes — each proves exactly what it says, no more:

Reference implementation — the runtime that defines the published fixtures.

Independent reproduction — a named party independently re-ran the published conformance surface and reproduced it (fixture hashes, deterministic decision output, canonical argument binding, deny-reason semantics). Not certification, implementation security, or production enforcement.

Certification (reserved — no entries yet) — a runtime passed the full published fixture set via a submitted, verified conformance report. Not implementation security or production enforcement.

Production enforcement (reserved — requires SP/1.0-Custody) — demonstrated fail-closed enforcement with capability custody in a deployed system.
